WHAT THIS PAGE IS FOR

A scientist-first operating view.

This page presents the current lunar-surface implementation of the committee complexity framework without hiding the assumptions. The core model uses relative rank within an approved peer population. Resource adequacy and stress are intentionally kept separate because they remain experimental hypotheses requiring historical calibration.

The NASA artwork is contextual only. It is not a model output and does not imply NASA endorsement of this model.

Research status

Working technical discussion draft for public technical review. This page is not an AIAA standard, recommended practice, or official AIAA position, and it is not a NASA product or endorsement. The 28 lunar-surface parameters are a proposed domain-specific pilot set and are not claimed to be the Canales/Bearden cislunar 28. Current normalized ranks include demonstration / engineering-judgment values; comparative interpretation requires an approved peer population and sourced mission data. Resource-adequacy and stress thresholds remain experimental until calibrated against historical outcomes.

MODEL BOUNDARIES

What it does — and what it does not do.

01

Peer-normalized complexity

Mission and system attributes are converted into relative ranks within an approved comparison population, then combined into the core Complexity Index.

02

Explicit provenance

Observed values, estimates, unknowns, parameter-set versions, and peer-group definitions remain traceable rather than being blended into a black-box score.

03

Separate resource stress

Budget, schedule, integration and test capacity, maturity, staffing, and reserves are tested outside the core index until historical outcomes support calibration.

04

Not a failure oracle

The current workbook is a working research testbed. It is not a finished standard, a validated predictive failure model, or a replacement for the source methodology.

LUNAR CONTEXT

Why the south-polar infrastructure matters.

NASA’s current lunar surface technology work emphasizes continuous localized power, autonomous systems, dust mitigation, mobility, construction, and in-situ resource utilization. Its Vertical Solar Array Technology work has studied autonomous vertical arrays on masts up to 20 meters to reduce shadowing and improve access to low-angle sunlight near the lunar South Pole.
